# Owino Live

Owino Live is a live streaming platform where viewers can discover live creators, watch streams, chat, follow creators, and interact with them.

## 🚀 Project

The platform will include:

- 👤 User registration and login
- 🔐 Secure authentication
- 📺 Live streaming
- 💬 Live chat
- ❤️ Follow/favorite creators
- 👤 Creator profiles
- ✅ Creator verification
- 🛡️ Moderation and reporting
- 💰 Credits and tipping
- 💳 Creator earnings and payouts
- 🔔 Notifications
- 📊 Creator dashboard
- 🛠️ Admin dashboard

## 🏗️ Technology

The project is planned to use:

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- LiveKit
- GitHub
- Vercel

## 🔒 Safety & Verification

Creators will go through an appropriate verification process before they can broadcast.

The platform will include tools for reporting, moderation, account restrictions, and protecting users.
